# AI·데이터 보안 체크리스트

- 대상: aggregate_quarterly 전처리 모듈 및 관련 제출물
- 점검 범위: Copilot 입력 프롬프트, preprocess.py,
  test_preprocess.py, Git 설정 확인 결과 및 작업 기록
- 판정 기준: 직접 확인한 자료와 작성자가 확인한 사실
- 주의: 담당 모듈에 대한 점검이며 팀 저장소 전체에 대한 판정은 아님

| 구분 | 번호 | 점검 항목 | 준수 여부 | 근거 |
|---|---|---|---|---|
| 데이터 | S1 | 제출물에 실존 인물의 실명·전화번호·이메일 등 PII가 포함되지 않았다. 더미 데이터를 사용했다. | 예 | 테스트에는 직접 만든 더미 수출액·환율을 사용하며 개인정보 필드가 없다. |
| 데이터 | S2 | 외부 AI에 기업 기밀·타인 코드·PII를 입력하지 않았다. | 예 | 제공된 Copilot 프롬프트 본문에는 함수 명세와 예시 조건만 있으며 기업 기밀·타인의 구현 코드·PII는 확인되지 않았다. 기록 상단의 작성자 이름까지 실제 입력했다면 별도 재판정이 필요하다. |
| 데이터 | S3 | 외부 데이터 사용 시 출처·라이선스를 확인하고 PII 열을 비식별 처리했다. | 해당 없음 | 이번 구현·테스트에는 실제 외부 데이터 대신 스키마와 더미 데이터를 사용했다. 실제 수출·환율 데이터를 사용하거나 제출할 때는 출처·이용 조건 및 개인정보 포함 여부를 별도로 확인한다. |
| 키 관리 | S4 | API 키·비밀번호가 소스코드에 하드코딩되어 있지 않다. | 예 | preprocess.py와 test_preprocess.py에서 API 키·비밀번호 하드코딩을 발견하지 못했다. 담당 함수는 키가 필요한 외부 호출을 하지 않는다. |
| 키 관리 | S5 | .env 파일이 .gitignore에 등록되어 있고, git ls-files 확인 결과 추적되지 않는다. | 예 | .gitignore 11번째 줄의 .env 규칙 적용을 확인했다. 공유된 git ls-files 점검 결과에 환경 파일 출력이 없어 현재 추적되지 않음을 확인했다. |
| 키 관리 | S6 | 커밋 히스토리에 키가 노출된 적이 없다. 노출 시 폐기·재발급 완료를 명기한다. | 해당 없음 | 담당 전처리 모듈과 테스트에는 키를 사용하는 파일이 없으며 .gitignore도 커밋했다. |
| 키 관리 | S7 | 키·비밀 값을 print·log·스크린샷으로 전체 출력하지 않았다. | 예 | 담당 전처리 코드에는 print·로깅 호출이 없고 키를 다루지 않는다. 최종 제출 로그·스크린샷에도 비밀 값이 없다. |
| AI 사용 | S8 | AI 사용 내역인 프롬프트·채택·수정을 과제 규정에 따라 기록·첨부했다. | 예 | prompt_log.md에 실제 프롬프트 원문, 원본 커밋 해시, 발견 결함 1건과 수정 내역을 기록했다. README에 실제 테스트 결과 전문을 기록했다. |
| AI 사용 | S9 | LLM 기능 포함 시 사용자 입력 검증과 출력 형식 검증을 적용했다. | 해당 없음 | aggregate_quarterly는 pandas 기반 집계 함수이며 실행 중 LLM을 호출하지 않는다. 개발 과정의 Copilot 사용은 서비스 내부의 LLM 기능과 구분한다. |
| AI 사용 | S10 | LLM 기능 포함 시 시스템 프롬프트에 비밀 정보를 포함하지 않았다. | 해당 없음 | 담당 전처리 모듈에는 LLM 시스템 프롬프트가 없다. 팀 시스템의 다른 모듈에 LLM 기능이 있으면 별도로 점검한다. |
