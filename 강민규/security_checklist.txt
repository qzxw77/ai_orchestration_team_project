예
근거: 테스트 데이터는 직접 만든 더미 수출액(억 달러 단위)이고, 이름은 과제 양식의 작성자 표기에만 있음

데이터 S2 외부 AI(챗봇·API)에 기업 기밀·타인 코드·PII를 입력하지 않았다.
예
근거: Copilot Chat에는 함수 명세 프롬프트와 더미 테스트 파일만 넣었고 실데이터, 키, 개인정보는 넣지 않았음

데이터 S3 외부 데이터 사용 시 출처·라이선스를 확인하고 PII 열을 비식별 처리했다.
예
근거: detect_anomaly 구현과 테스트에는 외부 데이터를 쓰지 않았음 (관세청 수출 통계는 PII가 없는 공공 통계)

키 관리 S4 API 키·비밀번호가 소스코드에 하드코딩되어 있지 않다.
예
근거: detect_anomaly는 외부 호출이 없어 키를 쓰지 않고, 코드 리딩 체크리스트 4번에서 키 문자열이 없음을 확인했음

키 관리 S5 .env 파일이 .gitignore에 등록되어 있고, git ls-files 확인 결과 추적되지 않는다.
예
근거: .gitignore에 .env, .env.*가 등록되어 있고, git ls-files 결과에 .env가 없음

키 관리 S6 커밋 히스토리에 키가 노출된 적이 없다 (노출 시 폐기·재발급 완료를 명기).
예
근거: 저장소 생성 직후 코드보다 먼저 .gitignore를 커밋했고, 내 커밋에는 키를 쓰는 파일이 없음

키 관리 S7 키·비밀 값을 print/log/스크린샷으로 전체 출력하지 않았다.
예
근거: detect_anomaly에는 print, 로그 출력이 없고 키를 다루지 않음

예
근거: detect_anomaly는 LLM 기능을 쓰지 않아 해당 사항 없음 

10주차
데이터 S1 제출물에 실존 인물의 실명, 전화번호, 이메일 등 PII가 포함되지 않았다. (더미 데이터 사용)
예
근거: fetch_fx_rates 테스트(test_fetch_fx_rates.py, test_fetch_fx_rates_guard.py)와 detect_anomaly 안전망 테스트의 환율, 수출액은 모두 직접 만든 가상의 더미 값이고, 실제 ECOS 응답은 저장소에 넣지 않았음. 
 
데이터 S2 외부 AI(챗봇, API)에 기업 기밀, 타인 코드, PII를 입력하지 않았다.
예
근거: Copilot Chat에는 정밀 프롬프트, 내 코드(data_loader.py, forecaster.py), 더미 데이터 테스트 파일만 넣었고 실제 ECOS 키와 실제 응답 데이터는 넣지 않았음 (프롬프트의 키 자리는 <키>로 표기, 테스트는 가짜 키 TESTKEY0123456789 사용). 
 
데이터 S3 외부 데이터 사용 시 출처, 라이선스를 확인하고 PII 열을 비식별 처리했다.
예
근거: fetch_fx_rates가 받는 자료는 한국은행 ECOS Open API의 원/달러 매매기준율(통계표 731Y001, 항목 0000001)로, 개인정보 열이 없는 공개 경제 통계임. 이용 조건은 한국은행 경제통계 Open API 이용약관을 따르고 출처는 한국은행 경제통계시스템(ECOS)으로 표기함. 
 
키 관리 S4 API 키, 비밀번호가 소스코드에 하드코딩되어 있지 않다.
예
근거: data_loader.py는 파일 맨 위 load_dotenv() 후 os.getenv("ECOS_API_KEY")로만 키를 읽고, 코드에 키 문자열이 없음. 
 
키 관리 S5 .env 파일이 .gitignore에 등록되어 있고, git ls-files 확인 결과 추적되지 않는다.
예
근거: .gitignore 2~4줄에 .env, .env.*, !.env.example이 등록되어 있음. ECOS 키를 넣는 .env는 로컬에만 두고 커밋하지 않음
 
키 관리 S6 커밋 히스토리에 키가 노출된 적이 없다 (노출 시 폐기, 재발급 완료를 명기).
예
근거: 원격 저장소 전체 브랜치의 커밋 히스토리를 검사함. 커밋에서 키가 나온 적 없음
 
키 관리 S7 키, 비밀 값을 print/log/스크린샷으로 전체 출력하지 않았다.
예
근거: data_loader.py, forecaster.py에 print, logging이 없음. 

AI 사용 S8 AI 사용 내역(프롬프트, 채택, 수정)을 과제 규정에 따라 기록, 첨부했다.
예
근거: prompt_log.md의 "[data_loader] fetch_fx_rates" 항목에 사용 도구(GitHub Copilot Chat, Claude), 프롬프트 원문, 생성 원본 c800da7, 코드 리딩 결함 3건과 수정 커밋 79dc087, 48a8540을 기록함.

예

예
