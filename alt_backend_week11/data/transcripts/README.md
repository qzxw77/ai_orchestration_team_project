# 컨콜 텍스트 넣는 곳

- 파일 이름은 실적을 발표한 분기입니다. `2026Q3.txt`는 2026년 3분기 실적발표(4분기 전망 포함)이고, 2026Q4를 예측할 때 읽습니다.
- 내용: 실적발표 보도자료의 전망 문단 + 컨퍼런스콜 질의응답 정리. UTF-8로 저장합니다.
- 파일이 없으면 가이던스는 empty_input, 가이던스 비교는 "판단불가"로 나오고 나머지 계산은 그대로 됩니다.
- mock 모드(ANTHROPIC_API_KEY 없음)는 아래 표현을 규칙으로 읽으므로, 정리할 때 이 표현을 살려 쓰면 결과가 정확해집니다.
  - 분기: "2026년 4분기"
  - 가격: "상승" 또는 "하락" (둘 다 있으면 언급없음으로 읽음)
  - 출하: "D램 출하량은 10% 증가", "낸드 출하량은 5% 증가"처럼 D램, 낸드 뒤에 숫자와 %
  - HBM 관련 문장 한 줄
